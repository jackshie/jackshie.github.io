PttShop 隱私權政策

適用 App：PttShop
開發者：Liang-Zong Shie
聯絡信箱：bareo0101@gmail.com
生效日期：2026 年 11 月 13 日

本政策說明 PttShop 及其支援網站如何處理資料。PttShop 是搜尋與瀏覽 PTT 公開交易文章的獨立工具，並非 PTT 官方服務。

重點摘要：目前 App 不需要建立帳號，也沒有開發者自行架設的後端。關鍵字、收藏與閱讀等紀錄主要儲存在裝置中；搜尋與瀏覽時仍會連線至 PTT 等第三方服務，並非完全離線，也不代表第三方不會處理連線資料。

1. 儲存在裝置中的資料

為提供功能，App 會使用 Core Data 與系統偏好設定儲存以下資料：

  • 各看板的關鍵字清單、顯示名稱及排序。
  • 最近選用的看板、販售／徵求類型、關鍵字、時間範圍與手動選取的地區。
  • 收藏文章的標題、日期、連結與收藏時間。
  • 已閱讀文章連結，以及用於判斷新文章的搜尋條件和文章連結比對紀錄。

這些資料用來保留設定、顯示收藏及辨識新文章；目前不會由 App 上傳至開發者伺服器。資料可能依你的系統設定納入 iOS 裝置備份，相關備份由 Apple 或你選用的備份方式管理，不是 PttShop 自行提供的雲端同步。

2. 搜尋與瀏覽 PTT

你開始搜尋時，App 會直接向 PTT 網頁版發出 HTTPS 請求。請求會包含所選看板、搜尋關鍵字及查詢頁碼。地區篩選可能需要進一步讀取文章內容，以判斷交易地區。

PTT 會接收到建立連線所需的資料，例如 IP 位址、請求網址及一般連線資訊。開啟文章時，App 使用系統網頁元件；該網頁或其連結的第三方資源可能使用 Cookie、網站儲存或快取，並依各自政策處理資料。

App 不要求輸入 PTT 帳號或密碼。請勿將密碼、電話、身分證號或其他敏感資料當作搜尋關鍵字，因為關鍵字會包含在送往 PTT 的請求網址中。

3. 地區與裝置權限

地區篩選由你手動選擇，並依公開文章的標題或內文判讀，不使用 GPS 或要求裝置定位權限。目前核心搜尋功能亦不需要取用相機、麥克風或通訊錄。

若你主動使用複製文章連結功能，App 會將該連結寫入系統剪貼簿，供你貼到其他 App。

4. 廣告與 Google AdMob

提供橫幅廣告的 PttShop 版本使用 Google AdMob（Google Mobile Ads SDK）顯示廣告，並使用 Google User Messaging Platform（UMP）處理適用地區的廣告隱私同意選擇。舊版若未包含廣告功能，則不會透過這些 SDK 請求廣告。

本版設定為非個人化廣告處理，不以開啟跨 App 追蹤為使用前提；App 不會主動將搜尋關鍵字、收藏清單或閱讀紀錄傳送給 Google 作為廣告受眾資料。

依 Google 說明，廣告 SDK 可能處理裝置或 App 識別碼、IP 位址與其衍生的大略位置、廣告曝光與互動、當機及效能等資料，以提供廣告、衡量成效、分析及防止詐欺或濫用。非個人化廣告仍可能使用識別碼、Cookie 或本機儲存，不代表完全不處理資料。

UMP 會在啟動時更新同意狀態，並於需要時顯示同意表單；App 只在 SDK 確認可以請求廣告後才載入橫幅。你可以從搜尋結果右側的「隱私與支援」（省略號圖示）開啟隱私權政策；若你的地區或同意類型要求提供調整入口，同一選單會顯示「廣告隱私選項」，供你重新選擇。

你可拒絕表單中提供的可選資料用途；廣告能否顯示及類型會依你的選擇與 Google 規則而異，文章搜尋不以同意廣告為前提。不同意或無法完成必要流程時，廣告可能不會顯示。

Google 及參與廣告服務的第三方，可能依其政策於你所在區域以外處理資料。其資料保留、刪除、分享及隱私權利處理方式，請參閱下列政策；若 SDK、廣告供應商或資料用途變更，開發者會同步更新本政策。

  • Google 隱私權政策
  • Google 如何處理使用其服務之網站或 App 的資訊
  • Google Mobile Ads SDK 資料揭露說明

5. 聯絡支援時提供的資料

若你主動寄信至 bareo0101@gmail.com，開發者會收到你的電子郵件地址、信件內容，以及你自行提供的裝置資訊、截圖或附件。這些資料用於回覆問題、排查錯誤及處理你的請求，並由電子郵件服務處理與保存。

請只提供必要資訊並遮蔽個人資料，不要傳送密碼、驗證碼、付款資訊或身分證件。若希望刪除先前提供的支援資料，可透過同一信箱提出，開發者會在必要的身分確認後，於可行且無須依法保留的範圍內處理。

6. 資料保留、刪除與備份

本機設定與紀錄會保留至你移除相關項目或刪除 App。你可在 App 中管理關鍵字與取消收藏；目前沒有獨立清除全部閱讀與搜尋比對紀錄的介面。

若要移除整個 App 的本機資料，請使用 iOS 的刪除 App功能，而不是會保留文件與資料的「卸載 App」。既有系統備份、郵件副本或第三方網站保存的資料不會因此一併刪除，須依各服務提供的方式另行管理。

開發者沒有本機資料的伺服器副本，無法替你讀取、恢復或遠端刪除裝置中的收藏與設定。保留期限與資料權利若涉及 PTT、Google、Apple 或電子郵件服務，請另參閱各服務的政策與聯絡管道。

7. 本支援網站

隱私政策與支援頁使用 GitHub Pages 託管，頁面本身沒有加入廣告、分析追蹤程式、聯絡表單或外部字型。你透過郵件連結聯絡支援前，網站不會代你寄送信件。

依 GitHub 說明，造訪 GitHub Pages 時，GitHub 會基於安全目的記錄訪客 IP 位址。相關處理請參閱 GitHub 隱私權聲明及 GitHub Pages 資料收集說明。

8. 安全與第三方服務

App 對 PTT 的請求使用 HTTPS，但任何網路傳輸與裝置儲存都無法保證絕對安全。請保持裝置與作業系統更新，並避免將敏感資料放入關鍵字或問題截圖。

第三方網站、文章連結及服務有其獨立的資料處理方式；本政策不代替其隱私政策。PttShop 不提供付款或交易託管，也不會要求你提交交易對象的銀行或身分資料。

9. 政策更新與聯絡

若功能、第三方服務或資料處理方式改變，會於此頁更新政策與生效日期；重大變更將視情況以適當方式告知。你可隨時透過本頁查看最新內容。
